  別の論点（候補。誤検出がありうる）: string literal の中の `${name}` に W の診断を出し、``= help: interpolation is written #{...}`` を付けてほしい。JS、Kotlin、Dart、shell の癖で `"${x}"` と書くと、Emela では `$`、`{`、`}` がただの文字なので、診断なしに `${x}` のままの文字列になる（上の使い捨ての Pome で確かめた）。失敗の message のように、実行しないと見えない所で起きる。`$` は pattern や shell の文字列で普通に使うので、`${` の直後が名前で `}` で閉じる形に限る。それでも shell の script や template を書いた文字列では誤検出になるので、候補にとどめる
