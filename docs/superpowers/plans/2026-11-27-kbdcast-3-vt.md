# サブプロジェクト 3: VT Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 端末の出力（文字列）から、agg 1.9.0 の avt 0.18.0 と同じ画面を作る VT と、PTY の bytes を文字列にするストリーム用の UTF-8 デコーダを、root の Pome に作る。

**Architecture:** `Utf8` は WHATWG の UTF-8 decoder をストリームで行う。`Vt.Parser` は DEC の状態機械で文字の列を action の列にし、`Vt.Screen` はセルと行の操作、`Vt.Terminal` は action を avt と同じ意味で解釈し（kbdcast の返事と modifyOtherKeys を足す）、`Vt` が公開 API をまとめる。正解は、avt 0.18.0 を Rust の harness から呼んで生成した画面のスナップショットの表（`test/vt_golden.emel`）。

**Tech Stack:** Emela（版は `mise.toml`）、JS ターゲットを Bun で、brix（assert と pbt）、Bun 上の TypeScript（道具と正解役）、Rust（avt の harness）。

**Spec:** `docs/superpowers/specs/2026-11-27-kbdcast-3-vt-design.md`

## Emela のコードを計画に書かない理由

この repo の規則（`AGENTS.md` の wish-first）では、実装する agent が spec を調べる前に自分で「こう書きたい」コードを書き、回り道を記録する。計画に Emela のコードを書くと、その発見が消える。そこで Emela のタスクには、ファイル、公開する名前と型、振る舞い、テストの入力と期待値、手順だけを書く。TypeScript と Rust と JS（道具と正解役）は、完全なコードを書く。

## Global Constraints

- Emela の版を**固定する**のは `mise.toml` の `"github:emela-lang/emela"` だけ。ターゲットは JS（`EMELA_JS_HOST = "bun"`）。`emela` は `mise exec --` で呼ぶ。
- 置き場所は root の Pome（`github.com/kisepichu/kbdcast`）。依存は増やさない（テストの brix だけ）。
- module の置き場所と公開する名前と型は、各タスクの Interfaces のとおり。Emela の制約で変える必要があれば、回り道として記録してから `NEEDS_CONTEXT` で止まる（自分で変えない）。
- `src/` には `@external` も effect も置かない。純粋な関数だけ。`@external` は `test/` の正解役（`test/utf8_oracle.mjs`）だけ。
- 振る舞いは spec の §4〜§8 で決まる。画面の振る舞いは avt 0.18.0 が正で、golden の表がそれを写す。avt のソースは、Task 2 の build の後に `~/.cargo/registry/src/*/avt-0.18.0/src/` にある（`parser.rs`、`terminal.rs`、`buffer.rs`、`line.rs`、`charset.rs`、`tabs.rs`）。計画の表と avt が食い違ったら avt に従い、食い違いを report に書く（spec と計画を直すのは manager）。
- avt は Apache-2.0。avt のコードを読んで振る舞いを写した module には、頭のコメントに「The behavior follows avt 0.18.0 (Apache-2.0, https://github.com/asciinema/avt)」の 1 行を入れる。
- library のエラーメッセージは英語。道具のメッセージと文書は日本語。コードのコメントは英語。
- 新しい単位を書くときは `AGENTS.md` の wish-first に従う（wish を書き、`mise exec -- bun tools/wish.ts check` し、wish だけを commit してから spec を調べて実装する）。回り道は `FRICTION(NNN)` とメモで記録する。黙って回避しない。メモは実装と同じ commit に、パスを指定して入れる。
- commit は branch `sp3/vt` に積み、最後に PR を作って merge commit で main に入れる。message は `type: 日本語の説明`。`git commit --no-gpg-sign` を使う。`--no-verify` は使わない。`git add` はパスを指定する（`-A` や `.` を使わない）。
- emela-lang の repo（emela、x、brix）には、issue、PR、コメントを出さない。

// Test-only oracle: the UTF-8 decoder of the WHATWG Encoding Standard (TextDecoder), which replaces each maximal
// subpart of an ill-formed sequence with U+FFFD. `ignoreBOM` keeps a leading U+FEFF, as Utf8 does.
// Returns what each chunk decodes to with `stream: true`, and then what the final flush gives.
export function decode(chunks) {
  const decoder = new TextDecoder("utf-8", { ignoreBOM: true });
  return [...chunks.map((chunk) => decoder.decode(chunk, { stream: true })), decoder.decode()];
}
```

// What avt 0.18.0 (the terminal emulator of agg 1.9.0) makes of terminal output, for the kbdcast VT's golden tables.
// tools/gen-vt-golden.ts turns the output into src/vt/width_table.emel and test/vt_golden.emel.
//
//   avt-golden width                 one line per range of code points that avt draws two columns wide:
//                                    `<first>\t<last>` in hex
//   avt-golden cases [seed] [count]  one line per case: `<name>\t<cols>\t<rows>\t<input>\t<snapshot>`, where the
//                                    input and the snapshot are code points in hex separated by `.` (so that no
//                                    character needs escaping). The table uses the default seed and count; other
//                                    values are for exploring.
//
// The snapshot is the screen as agg sees it (`Snapshot::same_visual` in agg: the cells of the view and the cursor),
// plus the cursor keys mode. Its lines, joined by "\n":
//   `cursor <col> <row>` or `cursor hidden`
//   `keys normal` or `keys application`
//   one line per row of the view: for each cell, `\u{1}<pen>\u{2}` when its pen differs from the cell before it
//   (the first cell is compared with the default pen), then the character, or `\u{3}` for the right half of a wide
//   character. <pen> is `<fg>,<bg>,<intensity>,<attrs>`: a color is `-`, `i<index>` or `#rrggbb` (lower-case hex),
//   the intensity is `n`, `b` or `f`, and the attributes are the letters of italic `i`, underline `u`,
//   strikethrough `s`, blink `k` and inverse `r` that are set, in that order.
use avt::{Color, Pen, Vt};
use unicode_width::UnicodeWidthChar;

const DEFAULT_SEED: u64 = 20261127;
const DEFAULT_COUNT: usize = 2000;

fn main() {
    let args: Vec<String> = std::env::args().collect();
    match args.get(1).map(String::as_str) {
        Some("width") => width(),
        Some("cases") => {
            let seed = args.get(2).map_or(DEFAULT_SEED, |s| s.parse().expect("the seed is a number"));
            let count = args.get(3).map_or(DEFAULT_COUNT, |s| s.parse().expect("the count is a number"));
            cases(seed, count)
        }
        _ => {
            eprintln!("usage: avt-golden width | avt-golden cases [seed] [count]");
            std::process::exit(2);
        }
    }
}

// avt's Line::char_display_width: a character is two columns wide when it is above U+007E and unicode-width says 2.
fn width() {
    let mut start: Option<u32> = None;
    for c in 0x7fu32..=0x11_0000 {
        let wide = char::from_u32(c).is_some_and(|ch| ch.width() == Some(2));
        match (wide, start) {
            (true, None) => start = Some(c),
            (false, Some(s)) => {
                println!("{:x}\t{:x}", s, c - 1);
                start = None;
            }
            _ => {}
        }
    }
}

fn hex(s: &str) -> String {
    s.chars().map(|c| format!("{:x}", c as u32)).collect::<Vec<_>>().join(".")
}

fn color(c: Option<Color>) -> String {
    match c {
        None => "-".to_string(),
        Some(Color::Indexed(n)) => format!("i{}", n),
        Some(Color::RGB(rgb)) => format!("#{:02x}{:02x}{:02x}", rgb.r, rgb.g, rgb.b),
    }
}

fn pen(p: &Pen) -> String {
    let intensity = if p.is_bold() {
        "b"
    } else if p.is_faint() {
        "f"
    } else {
        "n"
    };
    let flags = [
        (p.is_italic(), 'i'),
        (p.is_underline(), 'u'),
        (p.is_strikethrough(), 's'),
        (p.is_blink(), 'k'),
        (p.is_inverse(), 'r'),
    ];
    let attrs: String = flags.iter().filter(|(on, _)| *on).map(|(_, c)| *c).collect();
    format!("{},{},{},{}", color(p.foreground()), color(p.background()), intensity, attrs)
}

fn snapshot(vt: &Vt) -> String {
    let cursor = vt.cursor();
    let mut lines = vec![
        if cursor.visible { format!("cursor {} {}", cursor.col, cursor.row) } else { "cursor hidden".to_string() },
        format!("keys {}", if vt.cursor_key_app_mode() { "application" } else { "normal" }),
    ];
    let default = Pen::default();
    for line in vt.view() {
        let mut out = String::new();
        let mut previous = default;
        for cell in line.cells() {
            if *cell.pen() != previous {
                out.push('\u{1}');
                out.push_str(&pen(cell.pen()));
                out.push('\u{2}');
                previous = *cell.pen();
            }
            if cell.width() == 0 {
                out.push('\u{3}')
            } else {
                out.push(cell.char())
            }
        }
        lines.push(out);
    }
    lines.join("\n")
}

fn run(name: &str, cols: usize, rows: usize, input: &str) {
    let mut vt = Vt::builder().size(cols, rows).scrollback_limit(0).build();
    vt.feed_str(input);
    println!("{}\t{}\t{}\t{}\t{}", name, cols, rows, hex(input), hex(&snapshot(&vt)));
}

// SplitMix64: a fixed seed gives the same cases on every machine.
struct Rng(u64);

impl Rng {
    fn next(&mut self) -> u64 {
        self.0 = self.0.wrapping_add(0x9e37_79b9_7f4a_7c15);
        let mut z = self.0;
        z = (z ^ (z >> 30)).wrapping_mul(0xbf58_476d_1ce4_e5b9);
        z = (z ^ (z >> 27)).wrapping_mul(0x94d0_49bb_1331_11eb);
        z ^ (z >> 31)
    }

    fn below(&mut self, n: usize) -> usize {
        (self.next() % n as u64) as usize
    }

    fn pick<'a>(&mut self, xs: &[&'a str]) -> &'a str {
        xs[self.below(xs.len())]
    }
}

fn token(rng: &mut Rng, out: &mut String) {
    match rng.below(10) {
        0..=2 => out.push_str(rng.pick(&TEXT)),
        3 => out.push_str(rng.pick(&CONTROLS)),
        4 => out.push_str(rng.pick(&ESCAPES)),
        5 | 6 => {
            out.push_str("\u{1b}[");
            for i in 0..rng.below(3) {
                if i > 0 {
                    out.push(';');
                }
                out.push_str(rng.pick(&NUMBERS));
            }
            out.push_str(rng.pick(&FINALS));
        }
        7 => {
            out.push_str("\u{1b}[");
            if rng.below(2) == 0 {
                out.push('?');
            }
            out.push_str(rng.pick(&MODES));
            out.push_str(if rng.below(2) == 0 { "h" } else { "l" });
        }
        8 => {
            out.push_str("\u{1b}[");
            out.push_str(rng.pick(&SGR));
            out.push('m');
        }
        _ => out.push_str(rng.pick(&OTHER)),
    }
}

        for _ in 0..1 + rng.below(40) {
            token(&mut rng, &mut input);
        }
        run(&format!("random-{}", i), cols, rows, &input);
    }
}

#!/usr/bin/env bun
// Generates src/vt/width_table.emel and test/vt_golden.emel from avt 0.18.0 (the terminal emulator of agg 1.9.0).
// usage: mise exec -- bun tools/gen-vt-golden.ts [seed count]
// With a seed and a count, it writes test/vt_golden.emel from other random cases, to explore. Run it again without
// them afterwards, to put the table back.
import { writeFileSync } from "node:fs";
import { join, resolve } from "node:path";

const ROOT = resolve(import.meta.dir, "..");
const HARNESS = join(ROOT, "tools", "avt-golden", "Cargo.toml");
const WIDTH_OUT = join(ROOT, "src", "vt", "width_table.emel");
const CASES_OUT = join(ROOT, "test", "vt_golden.emel");

function harness(args: string[]): string[] {
  const command = ["cargo", "run", "--release", "--quiet", "--locked", "--manifest-path", HARNESS, "--", ...args];
  const run = Bun.spawnSync(command, { stdout: "pipe", stderr: "inherit" });
  if (run.exitCode !== 0) throw new Error(`avt-golden ${args.join(" ")} が失敗した`);
  return run.stdout.toString().trimEnd().split("\n");
}

// Code points written as `1b.5b.41` as an Emela string literal. Printable ASCII stays as it is, except `"`, `\` and
// `#` (which could start an interpolation); every other code point is a `\u{...}` escape.
function literal(codes: string): string {
  const chars = codes === "" ? [] : codes.split(".").map((h) => Number.parseInt(h, 16));
  const body = chars
    .map((c) => (c >= 0x20 && c <= 0x7e && c !== 0x22 && c !== 0x5c && c !== 0x23 ? String.fromCharCode(c) : `\\u{${c.toString(16)}}`))
    .join("");
  return `"${body}"`;
}

function fmt(path: string) {
  const run = Bun.spawnSync(["emela", "fmt", path], { stdout: "inherit", stderr: "inherit" });
  if (run.exitCode !== 0) throw new Error(`emela fmt が失敗した: ${path}`);
}

const explore = process.argv.slice(2);
if (explore.length !== 0 && explore.length !== 2) throw new Error("使い方: mise exec -- bun tools/gen-vt-golden.ts [seed count]");

if (explore.length === 0) {
  const ranges = harness(["width"]).map((line) => line.split("\t").map((h) => `0x${h}`));
  writeFileSync(
    WIDTH_OUT,
    `# Generated by tools/gen-vt-golden.ts from unicode-width 0.1.14 (tools/avt-golden). Do not edit.

## The first code point of each range of code points that avt 0.18.0 draws two columns wide (above U+007E, and
## two columns wide for unicode-width 0.1.14), in increasing order.
pub const WIDE_FIRST: List[Int] = [
${ranges.map((r) => `  ${r[0]},`).join("\n")}
]

## The last code point of each range in WIDE_FIRST, at the same position.
pub const WIDE_LAST: List[Int] = [
${ranges.map((r) => `  ${r[1]},`).join("\n")}
]
`,
  );
  fmt(WIDTH_OUT);
  console.log(`wrote ${WIDTH_OUT}: ${ranges.length} ranges`);
}

const cases = harness(["cases", ...explore]).map((line) => {
  const [name, cols, rows, input, snapshot] = line.split("\t");
  return `  ("${name}", ${cols}, ${rows}, ${literal(input)}, ${literal(snapshot)}),`;
});
writeFileSync(
  CASES_OUT,
  `# Generated by tools/gen-vt-golden.ts from avt 0.18.0 (tools/avt-golden). Do not edit.

## What avt makes of each input: the name of the case, the columns and rows of the screen, the input, and the
## snapshot of the screen after it. The format of the snapshot is in tools/avt-golden/src/main.rs.
pub const CASES: List[(String, Int, Int, String, String)] = [
${cases.join("\n")}
]
`,
);
fmt(CASES_OUT);
console.log(`wrote ${CASES_OUT}: ${cases.length} cases`);
```

- [ ] **Step 5: 速さを測る（permanent な test にしない）**
